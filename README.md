## Purpose

This repository defines a Proof Protocol mapping between the CIS Critical Security Controls® (CIS Controls®) Version 8.1 and Proof Protocol evidence, efficacy, and proof semantics.

The external framework supplies context describing what may be tested. Proof Protocol remains framework-agnostic and independently establishes whether a selected control performed as claimed.

## Architectural principle

> **Threat, control, audit, and regulatory frameworks are pluggable inputs to Proof Protocol. Proof Protocol is framework-agnostic.**

External frameworks identify what may be tested. Proof Protocol independently establishes whether a control worked and what evidence proves the result.
